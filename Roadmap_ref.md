## 📖 About This Repository

This repo is a structured, open study guide modeled on the Visualpath *DevOps Tutorials* curriculum.
Every topic lives in its own carefully formatted Markdown file, complete with diagrams, tables,
comparison charts, and real-world context — so you can learn DevOps the way it deserves to be learned.

> 💡 **Tip:** All diagrams are drawn with **Mermaid**, so they render natively on GitHub.
> All files include a table of contents — jump straight to what you need.
